# Construction ERP — 10-minute pitch demo script

For: the presenter running the client pitch. Serve the built app with `npm run build && npm run preview` (no internet needed) and open it on a 1440px+ screen. All data is sample data; **Help (?) → Reset demo data** restores it at any time.

## 1. The platform (1 min) — Enterprise Dashboard `/`
- Point to the **Construction Lifecycle** strip: CRM → Tender / Land → Estimation → Project → Procurement → Store → Site → Workforce / Equipment / Subcontract → Contracts → Billing → Finance → Quality & Safety → Variations / Claims → Handover → Reporting.
- Walk the 12 KPIs: 8 active projects, ₹320 Cr contract value, ₹214.5 Cr billed, ₹186 Cr cost, ₹28.5 Cr gross profit, receivables, payables, workforce, sites, claims, variations, safety.
- Right rail: pending approvals, alerts & risks, milestones, recent activity.

## 2. One platform, 19 applications (1 min) — 9-dot switcher
- Click the **9-dot** button (top right, left of the bell). Show the search, recent apps, and the 19 application tiles.
- Press **Ctrl + K** — search "Skyline" to show that projects, vendors, employees and pages are all searchable.

## 3. Winning work (1.5 min) — CRM → Tender → Estimation
- **CRM › Opportunity Management › Opportunity** — switch to **Board** view; drag a card to another stage.
- **Tender › Tender Management › Tender Registration → Add** — the multi-step tender creation wizard.
- **Tender › Evaluation › Technical Eligibility** — pass / fail scorecard.
- **Estimation › BOQ › BOQ Items** — edit a quantity inline; totals and GST recalculate.

## 4. Running the project (2 min) — Project
- **Project dashboard**: progress, cost summary, project health, milestones, site updates.
- **Project Structure › WBS** — expand the hierarchy with budget vs actual per node.
- **Planning & Control › Schedule** — Gantt with baseline, today line and delay flags; **Dependencies** shows the links.
- **Project Master › Status** → open **PRJ-001 Skyline Apartments**: detail tabs (Overview, Financial, Progress, Related Records, Documents, Activities, Approvals, History).

## 5. Supply chain & site (1.5 min) — Procurement → Store → Site
- **Procurement › Vendor Quotations › Rate Comparison** — best rates highlighted → **Select** a vendor.
- **Procurement › Purchase Order › PO → Add** — PO wizard.
- **Store › Inventory › Stock** — reorder / low-stock status.
- **Site › Daily Reports › DPR** — the daily progress report form; **Site › Progress › Progress Photos**.

## 6. People & equipment (1 min)
- **Workforce › Attendance › Daily Attendance** — person × day grid; click a cell to change P/A/L.
- **Workforce › Payroll › Payslip** — printable payslip.
- **Equipment › Ownership › Rented** — rented equipment with rental cost.

## 7. Money (1 min) — Contracts → Billing → Finance
- **Billing › RA Bill** → open a bill; **Billing › Bill Certification** → **Approve** with a comment.
- **Finance › Financial Reporting › P&L** — formatted statement with period comparison.

## 8. Control & close-out (0.5 min)
- **Quality & Safety › Quality › NCR** and **Safety › Incident**.
- **Variations › Approval**, **Claims › Negotiation** timeline, **Handover › Snag Management › Rectification** board.

## 9. Insight (0.5 min) — Reporting
- **Reporting › Executive Dashboard › Revenue**, then **+ Custom Report** — the six-step report builder (module → fields → filters → group by → chart → generate).

Close: "Every screen you saw shares one shell, one design system and one data model — 19 specialised applications on one platform."
